# P3 离职流程时序损失观测——协议 v1

> [English](p3-offboarding-temporal-outcome-v1.md) | 简体中文

## 状态与主张边界

**当前冻结的是观测器与可识别性实验设计，不是已经完成的现实风险校准。**

本协议在开展产品端校准前冻结 P3 第一个独立候选损失指标。当前代码与测试使用明确标记为合成的仪器验证数据，不作为真实损失、风险因子归属或 penalty 参数的证据。

既有 [Joint-Risk Identifiability v1](../formal/joint-risk-identifiability-v1.zh-CN.md) 负结果继续有效。`OFFBOARDING_RISK_FACTOR_IDS_V1` 保持空表。

## 研究域及单位

分析单位是预先枚举、完成跨系统身份绑定的**主体**及冻结时间窗 `[0,H)`。每个主体预先确定有效撤权时间 `t_eff`、非负允许过渡期 `g`，以及撤权前是否有被明确认可的访问资格。

主要候选 endpoint：

```text
Y_joint = 对枚举主体求和
          ∫ 1{联合权限现实状态违反冻结的时序策略} dt
```

单位为 **subject-seconds（主体秒）**。过渡窗口 `[t_eff,t_eff+g)` **按事先规定不计入主要指标**，但单独报告其持续时间；不把该窗口称作现实无害。

若撤权前有明确定义的访问资格，则 `t_eff` 之前预期状态为：

```text
HRIS active = true；IAM enabled = true；访问探针 = ALLOW
```

若预先定义撤权前不具有该访问资格，探针预期为 `DENY`。撤权前不要求会话数量必须大于零。

在 `t_eff+g` 之后，预期状态为：

```text
HRIS active = false；IAM enabled = false；
有效 IAM 会话数 = 0；独立访问探针 = DENY
```

任一必需条件已知违反时，该段联合状态计为违规；若没有已知违反但必需字段缺失，则该段**不可精确识别**。

两个保护性次要 endpoint 单独保存：

1. `Y_access`：撤权期限过后，合格真实访问探针仍能成功的持续时间。
2. `Y_disruption`：有效撤权时间之前，存在已冻结的访问资格却被拒绝访问的持续时间。

不能用产品字段 `enabled=false` 替代实际访问探针。

## 观测与来源义务

未来实验只在隔离环境中使用测试主体；HRIS、IAM/会话和实际访问探针须有独立只读观测通道。每次观测绑定跨系统身份、来源、事件时间、采集器身份及版本，以及单调时钟或有界时钟误差。

**两个时间端点的快照不能证明中间全程发生了什么。** 只有独立合格观测器提供“区间连续性证明/佐证”时才能把该区间按已知状态积分。参考代码中的 `INTERVAL_ATTESTED` 只是输入数据的声明；Python 模型本身并未证明该声明真实可信。

`SNAPSHOT_ONLY`、观测不可用、覆盖缺口、字段缺失和时钟边界不确定，均须输出上下界而非猜测值。

每个 endpoint 都报告 `[Y_lower,Y_upper]`；只有在规定假设下上下界相等，才能给出单一数值。策略边界附近的 `epsilon_clock` 误差区间保守标记未知。

### 工程先决条件

产品实测前，必须证明观测器足以支持声称的连续性，例如可信的状态变化日志**加**周期性对账及主动访问探针；或者具明确数学插值误差界的有界时延采集器。若只有轮询，就必须报告区间界，不能把离散采样改名为连续事实。

访问探针失败还可能来自网络不可达、凭据失效、身份配置或系统故障。使用探针代表授权能力前，必须冻结其身份、网络基线和失败判别规则。

## 对照条件与干预

前瞻实验在隔离测试身份上进行，使用可比较的随机 episode；若多个 episode 共用状态或故障域，则按共享影响域随机化。至少包括：

- 不变对照与单 effect；
- 同一主体的二重、三重 effect 组合；
- 不同主体的多 effect；
- 操作顺序和重叠时间对比；
- lost-ack、延迟回读、部分失败、证据缺失作为**执行/观测因素**，不能直接算作损失。

故意注入的违规只能发生在经过授权的隔离测试域内，不允许作用于真实员工或租户级生产权限。

## 竞争性结构假设

观察处理结果前冻结：

- `F_distinct`：HRIS 停用、IAM 禁用、会话撤销分别独立；
- `F_IAM_shared`：两个 IAM 操作共用因子，HRIS 独立；
- `F_all_shared`：三个操作共用因子。

预先定义 interaction family，以 `lambda=0` 为基线，并给出非负候选区间。这些都只是**候选假设**，不是已校准风险归属。

现有 `pairwise-shared-factor-min-v1` 的输出与 `Y_joint` 并非同一单位，除非先建立独立论证的单位映射，不能直接拿二者做数值拟合。

随机因子实验中的结果交互（例如 `J_AB = E[Y|AB]-E[Y|A]-E[Y|B]+E[Y|control]`）并不自动证实现有 registry 或 pairwise-min penalty。还需事先定义竞争模型对结果的预测、参数可识别条件、不确定性处理，以及独立留出验证。

## 冻结的资格与验收规则

产品数据只有满足以下条件才有资格进入损失分析：

1. 实验前冻结主体全集、跨系统身份、时序策略和时间窗。
2. 验证观测器独立性及读写权限隔离。
3. 记录时钟误差界、覆盖范围、缺失性和访问探针可达性。
4. 至少一个已知违规注入被识别、一个合规对照无假阳性、一次观测中断使不确定性扩大而不是被归零。
5. 不根据有利结果事后改指标。
6. 保留全部 episode、失败、合格与不合格数据，不筛选分母。
7. 校准数据与留出验证数据在共享影响域层面隔离。

进一步宣称校准成功，必须有事先冻结、能够区分竞争模型的观测对比、样本/不确定性论证，以及留出预测验证。

若现实观测不足，或竞争预测仍然不可区分，结果必须是**不可识别**。不得为了得到正结果，在事后修改因子划分、过渡期、指标或 penalty。

## 版本与停止条件

- 观测器：`baa_protocol/temporal_outcome.py`，v1。
- 参考测试：`tests/test_temporal_outcome.py` 与 `tests/test_temporal_collector.py`。
- 只读快照采集契约：`baa_protocol/temporal_collector.py`。该采集器可检测观测时点的违规、保留部分失效来源，但**永不**把两次采样升级为已证明的连续区间。证书/日志真实性及现场权限隔离仍需独立验收。
- 当前状态：仅合成仪器资格验证；**尚无产品损失校准，也不更新 registry**。
- 首次产品实验须冻结 BAA、AIOS、采集器、Keycloak/Odoo、workload SHA-256、策略和探针版本。
- 在独立采集器资格与隔离测试租户授权就绪前，停止于此，不触发实际权限更改。

## 与其他工作包的区分

P5 的实现级 refinement、P6 的性能成本基础测量可以并行推进，但有限状态模型证明和吞吐基准都不能代替 P3 独立损失识别义务。
